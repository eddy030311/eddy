# Ave Mujica 假面回廊

手机可玩的 2D 像素风肉鸽小游戏（同人）。单个 `index.html`，直接用浏览器打开即可。

- 8 名可选人偶：Doloris / Mortis / Timoris / Amoris / Oblivionis，以及便服版的三角初华 / 若叶睦 / 丰川祥子（见「便服的三人」）
- 每人都有近战、远程、闪避与专属技能
- 五章：△ 烛火之厅 → 鸦羽回廊 → ▽ 泪之水底 → 荆棘庭园 → 终幕 假面舞台，每章 5 节（4 节 + 救出人偶的 Boss 战）
- 每章有独立的特色机关：烛焰火柱 / 强风 / 积水减速 / 荆棘丛 / 聚光灯与坠落沙袋
- 每章 Boss 囚禁着一名人偶，击败后她会成为同伴，自动使用近战、远程与技能（不吃强化、不触发被动、不提供额外加成）
- 同伴有独立的生命与护甲；敌人多或空闲时贴着你，敌人少时主动上前；生命归零会倒下，你或其他同伴走到她身边停留约 2.6 秒即可救起
- 只要还有能行动的同伴，你倒下时不会立刻失败，而是等同伴赶来救治；没有同伴或同伴全部倒下时才算演出失败
- 护盾系统：伤害先由护盾承担，一段时间未受伤后自动恢复
- 69 种强化旋律（含护盾、燃烧、减速、连锁、留声机、雷鸣等流派）
- 房间类型：演出（战斗）、精英（每章一名小 Boss）、化妆间（休息）、后台商店、衣柜（宝箱）
- 难度：N1–N9 全部开放，可任意选择（「假面之下」没有难度选项）。每级新增一条需要做决定的规则并逐级叠加（暗门、取舍、词缀精英、代价旋律、严格节拍、乐队调度、有限谢幕、终焉），敌人生命与伤害每级 +6%
- 旋律稀有度：普通约 82%、稀有约 16%、传说约 2%；N5 起传说旋律只能从支线获得
- 节奏判定：每次按下近战 / 远程 / 技能都会按节拍判定 PERFECT / GREAT / GOOD / BAD / MISS（伤害 ×1.5 / ×1.25 / ×1.0 / ×0.6 / ×0.35），GOOD 以上累积连击，MISS 清零；被击中不算 MISS。设置里可调判定偏移
- 判定轨道：屏幕下方正中（离底部约 16% 屏高）有一条横向音游轨道，只在战斗中计判定（非战斗时轨道变暗，不判定、不积攒 Fever），每拍一个白键从右向左滑向判定线，判定字显示在判定线上方（Boss 血条在屏幕顶部正中）；Fever 中轨道变为彩色。原先脚下的节拍环与角色头顶的判定字已移除
- Fever 核心：只有节拍判定（以及各角色的专属充能）能积攒 Fever：PERFECT +8 / GREAT +6 / GOOD +4 / BAD 0 / MISS −3，连击 ≥30 时 ×1.5；同一拍同一按键重复按下记为 MISS。五人的 Fever 槽统一为 325、持续 9 秒；战斗中槽满时自动发动 Fever 并释放专属技能（不再有技能键）
- 场地效果：Mujica 的五个形态、各结局 Boss 的每个阶段、「假面之下」的所有 Boss 都会给舞台加上场地效果（提线、独角灯、荆棘舞台、暗谱、坠落的聚光灯、泪潮、静默、凋零、漩涡、魅惑），Boss 血条下方会显示当前效果
- 精英：精英就是精英房间里的小 Boss（两个世界一致，普通战斗不再出现金光精英）；生命大幅提高，半血后进入「暴走」，出招更快
- 专属技能（星之独唱、人偶之舞、低音结界、鼓点独奏、忘却之时）的持续时间与本次 Fever 时长一致（含延长音、回忆能力、狂热节拍的延长）
- PERFECT 判定文字与 S / SS 评价使用浅蓝色（#9fd4ff）
- 房间清空时若正在 Fever，Fever 立即结束，剩余时间按比例折回 Fever 槽（最多保留 80%），下次能更快再次发动
- 连击数在最后一次出手 2.5 秒后淡出，清场后隐藏（连击本身不中断）
- 弹幕强度：正式 Boss 出招间隔 +15%、弹幕量约 -17%；小 Boss 出招更快、精英攻击频率约 +30%，两者约三成子弹会多出一发偏角弹
- PERFECT 被动：Doloris 治疗自己与所有同伴 2 点；Mortis PERFECT 近战送葬 25% 以下残血（Fever 中 40%）；Timoris 回复 3 点护盾（同伴 2 点）；Amoris 每连续 4 个 PERFECT 射出一圈爱心；Oblivionis 抹去身边最近的敌弹
- 专属充能：Doloris 受伤、Mortis 送葬、Timoris 弹反与护盾挡伤、Amoris 连击 10 以上 PERFECT 翻倍、Oblivionis 闪避擦弹
- 旋律（强化）分四个流派，卡片上会标出「流派 · 稀有度」，共 71 段：普通 28 / 稀有 27 / 传说 16
  - 节拍（12）：围绕 PERFECT 和连击，如节拍器、稳拍、数拍、切分音、装饰音、致命之吻、连奏、共鸣爆发、雷鸣，以及改判类：数拍（MISS 25%→GOOD）、即兴（BAD 50%→GOOD）、切分音（GOOD 25%→PERFECT）、指挥家（BAD→GOOD，MISS 30%→GOOD）、绝对音感（GOOD→PERFECT）
  - 狂热（10）：围绕 Fever，如安可、延长音、返场、华彩、千面、余韵、血之契约、终焉之音、狂热过载、狂热节拍
  - 演奏（24）：近战、远程和攻击特效
  - 舞台（25）：生命、护盾、走位与经济
  - 不再有攻击速度类旋律
- 音游完整版：
  - 节拍闪避：子弹、红圈或敌人即将命中时踩拍闪避（PERFECT/GOOD 窗口内）= PERFECT 闪避，短暂慢动作并清掉身边子弹，随后反击冲击波，计入 PERFECT 与连击；离拍闪避不判定
  - 连击 10 / 30 / 50 / 100：舞台灯光逐级变亮、观众掌声，伤害 +5% / +10% / +15% / +20%
  - 每章结束出演出评价：PERFECT / GOOD / BAD / MISS、准确率、最大连击，评级 SS / S / A / B / C。SS ✿60 + 稀有旋律、S ✿40 + 旋律、A ✿25、B ✿10
  - Boss 出招对齐音乐节拍（后期阶段对齐半拍）
  - 回应同伴呼应的判定决定二重奏强度：PERFECT ×1.6、GOOD ×1.25、MISS ×0.8
  - 判定窗口所有难度一致（与 N1 相同，PERFECT 约为拍长的 ±22%）；设置里有「节奏辅助」（窗口放宽 35%）和节拍器「校准」（自动测出判定偏移）
- 最终 Boss（每个阶段）血量比原先少 25%
- 没有局外成长：每一局都从零开始；标题页的「幕后档案」只记录结局
- 第四结局：后台商店偶尔会免费提供「失落的第五乐章」
- 过场：每章第三节前有一段「幕间」剧情（Ignis / Aer / Aqua / Terra / Quinta Essentia），精英小 Boss 倒下时有临别台词
- 邂逅、商店、化妆间、衣柜、精英、Boss 房间都有开场动画与越肩视角
- 每个 Boss 都有自己的战斗曲（巴洛克圆舞曲、塔兰泰拉、音乐盒 trip-hop、探戈、工业、摇摆大乐队、synthwave……）
- 启动时播放开场动画（可跳过），结束后进入标题页
- 第一世界章节池：原有 4 章 + 10 个以 Ave Mujica 歌曲为灵感的新章节（KiLLKiSS、Imprisoned XII、Alter Ego、Georgette Me Georgette You、顔、天球のMúsica、黒のバースデイ、Choir 'S' Choir、Ether Eater、神さま、バカ），每局随机抽 4 章，第 5 章固定为 Mujica；每章有独立的 3D 场景、Boss、战斗曲、精英与剧情（文案为原创，不引用歌词）
- 精英房间：一半几率遇到本章专属精英，另一半从全部精英池里随机
- 3D 渲染：所有地图与障碍物、强化图标、全部 71 种怪物 / 精英 / Boss（Mujica 除外）都用 three.js 在代码中建模，再经像素化处理（降采样、哥特调色板抖动量化、描边）输出为与角色同密度的像素画；强化图标、七种门的图标、每名角色的四个操作图标同样走像素化流程（不再使用提示词生成的图片）。房间烘焙电影级调色（压暗、泛光、冷暖分离），运行时有摆动的体积光束、浮尘与暗角（vendor/three.min.js，r128，MIT）；不支持 WebGL 时自动退回 2D 绘制
- 「假面之下」入口：完成任意一个结局后在标题页开放，点进去是一页分岔——「祥子的夜」（第二世界）、「星之约」（第三世界）与「镜中的睦」（第四世界）。三个世界都以剧情为主：敌人与 Boss 的生命和伤害都降到 70%，每个战斗房间只有 2 波敌人。
- 第二世界「祥子的夜」：只能以丰川祥子（Oblivionis）游玩；所有怪物、精英与 Boss 都是专为第二世界绘制的高精度模型。
- 第一世界的怪物、精英小 Boss 与 Boss（Mujica 除外）也全部用代码重绘为高精度模型现代都市背景，五章分别讲述五位成员各自的困境（四位同伴的心结 + 你自己的镜像），有独立的场景、敌人名称、Boss、剧情与配乐
- 配乐与音效全部由 WebAudio 实时合成：管风琴、羽管键琴、失真吉他、双踩、合唱、钟声（原创旋律，D 和声小调）

## 安卓安装包

`dist/AveMujica.apk`：横屏全屏、离线运行（字体与图片都打包在内）。桌面图标在 `android/icon/icon512.png`。剧情文字改动后先运行 `python3 android/update_fonts.py` 补齐字体，再在 `android/` 目录运行 `./build.sh` 重新构建（需要 Ubuntu 包 android-sdk-platform-23、aapt、apksigner、dalvik-exchange、zipalign 与 JDK）。
签名密钥默认生成在 `~/.ave_mujica_release.keystore`，不在仓库里；换了密钥的新版本需要先卸载旧版再安装。

## 设置

主菜单「设置」：帧率 60 / 120（120 需要高刷新率屏幕，APK 会请求设备最高刷新率）、语言 中文 / English / 日本語（全部文本含剧情均已翻译，切换后回到标题画面）、音乐与音效开关。

## 回忆与委托（局外收集）
- 主界面「回忆」：5 名人偶 + 便服三人各 6 片记忆 + 8 页「Mujica 的剧本」，共 56 片，可随时阅读。
  - 每人的 I–III 为「假面之上」（舞台上的人偶），IV–VI 为「假面之下」（动画中真实的她）；按顺序获得，读起来是一段完整的小故事。
  - 获取：救出人偶时必得她的一片；章节 S / SS 评价、击败精英（20%）、打开衣柜（30%）、完成委托各得一片；抵达第二章后若一局都没拿到，落幕时保底一片。
  - 剧本页按里程碑解锁：首次抵达第三章、四个结局、通关「假面之下」、通关「星之约」、通关「镜中的睦」（老存档会自动补发）。
  - 便服三人的回忆是「台下的日常」（I–III）和「心底的话」（IV–VI），只有用她出战时才会拾得（精英、衣柜、章节评价、委托）。
- 集齐某人的 6 片后，用她出战获得专属「回忆」能力：
  - Doloris「星之约定」：Fever +1 秒，Fever 中 PERFECT 治疗翻倍
  - Mortis「两个人的舞台」：Fever +2 秒，送葬回复 3 生命
  - Timoris「这一次不会散」：最大护盾 +20，护盾恢复 +30%
  - Amoris「镜头之外」：连击 30 以上暴击率 +15%
  - Oblivionis「不再逃避」：Fever +1 秒
  - 三角初华「自己的光」：Fever +1 秒，最大生命 +10
  - 若叶睦「想好好说出来」：「沉默的观察」只需静止 0.35 秒
  - 丰川祥子「夺回来」：「不服输」上限提高到 +90%
- 演出委托：同时有 3 个（如单局 PERFECT 数、最大连击、PERFECT 闪避、S 评价、用指定人偶抵达某章、以更高难度抵达第三章……），每次落幕时结算，完成后获得一片记忆，并换上新委托。

## 同伴系统

同伴不加数值，而是像乐队成员一样配合：
- 定位：Doloris 领唱（跟着你打同一个目标）、Mortis 影（绕后夹击、收割残血）、Timoris 低音（挡在你和威胁之间拦子弹）、Amoris 节拍（绕着你踩拍出手）、Oblivionis 指挥（守在身后、最常呼应你）。
- 判断：会预判子弹和红圈并躲开（有反应时间，偶尔失误）、残血时撤到低音身后、你残血时挡在你前面、挑最有威胁的目标、看时机放技能、冒险或放弃救人，并用简短喊话提示。
- 呼应 → 二重奏：同伴头顶出现 ♪ 并标记敌人时，攻击该敌人即可打出两人专属的二重奏（10 种组合），踩拍触发「完美呼应」。
- 掩护：你站在红圈里时，附近的同伴会冲过来把你推开。
- 邂逅里帮助她会获得「默契」：她更常呼应你，与她的二重奏必定完美。

## 性能

生成的怪物精灵、房间、图标会存入 IndexedDB，之后启动直接读取；战斗中不再进行任何 3D 构建，首次进入某个世界前会显示「调音中」进度条一次。手机端关闭全屏柔光与胶片颗粒。

## 电脑版
- 网页版在电脑浏览器里会自动切换为电脑界面：整套界面按窗口大小等比放大（沿用横屏排版），右下角显示带键帽的操作栏（含 Fever 充能环），鼠标瞄准并显示随节拍收缩的准星，菜单有悬停效果，设置里可切换窗口 / 全屏。手机端不受影响。
- Windows 便携版：`bash tools/desktop/build.sh` 生成 `dist/AveMujica-Windows-x64.zip`（Electron 33，约 130MB，超过 GitHub 单文件上限，不随仓库提交）。解压后运行 `AveMujica.exe`，F11 或 Alt+Enter 切换全屏，存档保存在本机。

## 假面之下（第二世界）的 Boss
- 每章的 Boss 都是那一章的她本人戴着假面的另一面（与终章的祥子相同）：Doloris「只为一人歌唱的我」、Mortis「替她开口的另一个我」、Timoris「不敢真正加入的我」、Amoris「想被所有人看见的我」。
- 所有 Boss（含终章祥子）都是三个阶段；开战前、每次转阶段、击败后都有对话剧情，击败后她才会加入队伍。
- 第一世界 Boss 房里关着下一位同伴的笼子：哥特式金色鸟笼（锁链、假面纹章穹顶、玫瑰藤、挂锁、天鹅绒坐垫），先画矢量再缩成游戏调色板的像素风；击败 Boss 后笼门打开、栏杆弯折、挂锁掉落

## 星之约（第三世界）
- 入口：标题页「假面之下」→ 分岔页选择「星之约」。和第二世界一样是一整局 2D 像素肉鸽，五章连续推进，没有难度选项。
- 由丰川祥子登台，三角初华从第一个房间起就作为同伴跟在身边。故事围绕两人的日常，恋爱感点到为止：放学后的天台、雨天的商店街、夏日祭、小时候相遇的星之岛、山顶天文台。每章有开场剧情、第二个房间的幕间对话、Boss 战前与每次转阶段的对话，以及通关后的结尾剧情。

## 在线更新（安卓版 / Windows 版）
- 正式版放在仓库的 `release` 分支：`ave_mujica_roguelike/update/manifest.json` 列出每个文件和它的 SHA-256，`update/www/` 是游戏文件本身。
- 已安装的游戏启动约 6 秒后，会去读这份清单（先试 raw.githubusercontent.com，连不上再试 jsDelivr）。发现版本号更高时，在标题画面或选人页弹出「发现新版本」，显示版本号、更新内容和需要下载的大小；局内不会打断，会等回到标题画面再提示。设置里也有「检查更新」。
- 玩家点「立即更新」后，外壳只下载有变化的文件（没变的直接从当前版本复制），逐个校验 SHA-256；全部成功才替换旧版本并重新载入。任何一个文件出错都会放弃这次更新，继续使用原来的版本。存档放在 localStorage，不受影响。
- 安卓：下载到应用的私有目录；如果之后装了更新的 APK，会自动改用 APK 里的版本。Windows：下载到用户数据目录（%APPDATA%\Ave Mujica\update）。
- 网页版本来就只有一个地址，不做这个检查。
- 发布新版本：`tools/release/release.sh "1.1" "更新内容一" "更新内容二"`。它会把 `update/version.json` 的版本号加一，打包游戏，推到 `release` 分支；然后重新构建 `dist/` 里的 APK 和 Windows 包，让新下载的人直接是最新版。只有执行这一步，玩家才会收到更新。
- 第一次需要大家装一次带更新功能的版本（v1.0），之后都会自动提示。

第一世界「假面回廊」变成一整片开放世界，五个章节是地图上的五座剧场；踩拍判定换成「技能菜单 + 短谱面」；五名人偶按定位重新设计；画面升级；加入存档。「假面之下」的祥子之夜、星之约、镜中的睦结构不变，但战斗也换成了新的技能系统。开放世界的代码在 `index.html` 最后一个独立的 `<script>` 里，主程序只在 `bound`、`updEnemy`、`render`、`rollUps`、`takeDoor` 等处加了 `G.ow` 分支。

### 五座剧场
- 「假面回廊」整个变成一片开放世界：按「开演」选好人偶，播完序幕就从营地出发。
- 地图上从营地往东北排着五座剧场，越远越靠后，第五剧场在原来失落剧场的位置。每座剧场就是一章：走进去后按原来的回廊方式进行（房间、门、被囚禁的同伴、Boss、过场），章节结束回到剧场门口，下一座剧场的大门打开。
- 小地图上闪金光的是下一座剧场；还没轮到的剧场上了锁，可以在门口把下一座标在地图上；演完的剧场会拉上幕布。
- 第五剧场是 Mujica 的终章，结局和以前一样。打完一章回到地图时，路上会多出一批更强的怪物；地图怪物的强度至少跟当前章节一样。
- 救出的同伴会跟着你在地图上走，落得太远会自动追上来；地图上她们只理会已经盯上你的怪物。

### 技能与谱面（取代踩拍判定）
- 普通攻击不再判拍。命中敌人、击倒敌人、受到伤害会积攒「乐章值」（HUD 上原来的 Fever 槽）。
- 乐章值满后按技能键（E / Q / I、手柄 Y、触屏技能键）打开技能菜单，游戏暂停。每个人偶有 3 个技能：原来的专属技能（增益型）加上两个新技能，按 1 / 2 / 3 或点选。
- 选好后打一段 3～4 秒的短谱面（5～8 个音，上下两条轨，跟着音乐的拍子；没开音乐时跟节拍器）。按准确率决定倍率 ×1.0～×1.6：增益技能延长持续时间，攻击技能提高伤害。全 PERFECT 会显示 FULL PERFECT。可以按「跳过」或在菜单里勾选「跳过谱面」，直接以 ×1.0 释放。
- 键位：上轨 D / F / ↑，下轨 K / L / ↓，空格打离得最近的音；触屏用下方两个大按钮或直接点轨道；手柄左扳机 / X / 十字键左上 = 上轨，右扳机 / RB / 十字键右下 = 下轨，A / B = 最近的音。
- 释放任意技能都会进入 Fever（换成 Fever 曲目、受到伤害减半）：专属技能 9 秒，新的增益技能 6～8 秒，攻击技能 3.5 秒，所以和 Fever 有关的旋律对每个技能都有效。

|---|---|---|
| Doloris / 初华 | 流星雨：连续降下 10 颗流星，每颗 26 范围伤害 | 安魂曲：回复自己和同伴 15% 生命、扶起倒下的同伴，6 秒内每秒回复 2% |

- **强音**：连击每满 8 下，或谱面里每个 PERFECT，算一次强音。人偶原来「每个 PERFECT」的被动（治疗、护盾、爱心、抹弹、送葬线）和相关旋律都改成按强音触发。
- **连击**：现在按命中计数，3 秒没有命中或受伤会中断（「换气记号」可以挡住受伤中断）。
- **演出评价**：每章结束时按这一章技能谱面的准确率评定（本章谱面音符少于 8 个时不评）。
- 失效的旧旋律改了效果：稳拍（谱面倍率 +0.05）、正拍（攻击技能伤害 +20%）、圆滑奏（增益技能持续时间 +15%）、回拍（闪避后 1 秒内的下一次命中视为强音）；判定类旋律（节拍器、数拍、切分音、指挥家等）改为作用在技能谱面上。
- 委托：「PERFECT 闪避」改为「满分谱面」，PERFECT 数量和最大连击的目标按新规则调整，「发动 Fever」改为「释放技能」。
- 「假面之下」的战斗也换成了这套技能系统。

### 开放世界
- **程序生成世界**：112×84 格（约 1800×1350 像素）的连续地图，每局重新生成：噪声森林、蜿蜒的河（沉没海岸是海和潮沟）、道路与桥、营地、三栋废墟小屋围成的广场、神社、五座剧场（第五座在东北角原来失落剧场的位置）、西北角被石圈围住的隐藏林地。生成后会检查连通性，凡是能走的地方都保证能从营地走到。
- **探索**：战争迷雾（没去过的地方是黑的，去过但不在视野里的会变暗），右上角小地图只显示已探索的部分，以及打听到或发现的地点。
- **白天 / 黄昏 / 夜晚 / 黎明**：一轮 7 分钟。夜里视野变小、怪物更敏锐，手风琴师会回营地，没有脸的人偶师只在夜里出现，倒映月亮的水洼只在夜里出现。
- **怪物 AI**：待机、漫游、巡逻、调查（攻击会发出声音，附近的怪物会过来看）、警戒（头上冒「!」，并叫醒同一群的同伴）、追击（沿用原有的攻击方式）、撤退（假面和乌鸦残血会跑）、返回（追太远或跟丢就回原地并回血）。离玩家很远的怪物不计算，保证性能。区域危险度随离营地的距离分 4 级。
- **NPC**：行商的无面人（卖旋律、包扎；记得你在别处做过的事，会打折或替你付过账）、街角的手风琴师（白天在广场演奏，站在附近技能谱面的判定放宽；晚上回营地；把乐谱还给他会送传说旋律）、提灯的旅人（沿路在几个地点之间走，会告诉你终章剧场和石圈的位置）、躲在废墟里的女孩（可以护送回营地，被怪物碰到三次会逃走）、没有脸的人偶师（解锁后夜里出现，用最大生命换传说旋律）。遇到怪物时，除了商人都会躲开。
- **事件（都有不打架的解法）**：遗失的乐谱、受伤的骑士、怪物巢穴（会不断冒出怪物；可以捣毁、撒花瓣引开或绕过去）、坏掉的人偶（修好后会跟着你帮忙打怪）、废弃的货摊、倒映着月亮的水洼。不同选择会影响之后 NPC 的反应和奖励。
- **隐藏区域**：石圈上有一块松动的石头，攻击或冲刺撞上去就会裂开，里面有宝箱和放着传说旋律的祭坛。
- **旋律**：沿用原有的 120 种旋律，另加 5 种只在漫游出现的探索型旋律：远眺、轻步、拾荒者、篝火的余温、寻宝直觉（要先在漫游里找到过隐藏林地才会出现）。来源：宝箱、事件、商人、巢穴。
- **死亡与永久解锁**：死亡结束本局，结算画面显示探索度、击倒数、旋律数。永久解锁的是内容而不是数值：新地区「沉没海岸」（第一次通关）、新 NPC「没有脸的人偶师」（第一次结束漫游）、新事件「倒映着月亮的水洼」（漫游两次）、新旋律「寻宝直觉」（找到隐藏林地）。
- **护盾**：漫游里没有「清理房间」，改为一场战斗结束（附近的怪物都脱战 2.5 秒）后按难度恢复护盾。
- **还没做的（之后的阶段）**：更多地区主题（失落城镇、崩坏教堂、废弃地下铁、冰封地区）与地形（洞穴、雪地）、地图上的游荡 Boss 与隐藏 Boss、NPC 更完整的作息与对话记忆、天气、更多事件；漫游里的文字目前只有中文。

### 角色差异化（依据「角色差異化與開放世界探索系統」提示词）
**分析与对应**：角色数值在 `CHARS`（基础生命、速度、攻击）和 `stats()`；伤害在 `doMelee` / `doRanged` / `hurtPlayer`；冲刺在 `doDash`；敌人察觉在漫游的 `owDet` / `owNoise` / `owEnemy`；NPC 与事件在 `owTalk` / `OWEV`；掉落在 `killEnemy` / `openChest`；经济是花瓣与行商。原来没有「出售物品」和「埋藏物资」，这次作为新模块加入（战利品 `OWMAT`、埋藏宝物 `owCaches`）。
**做法**：所有角色差异集中在一张表 `CROLE`（数值倍率）和 `CPASS`（探索被动：ID、作用系统、说明、触发提示），各系统只读 `cr(k)` / `cpas()`，以后加新角色只需要加一行。`CPDBG()` 可以在控制台查看当前角色的被动和倍率。战斗数值在地图和剧场里都生效，探索被动只在地图上生效。

- 地面逐像素绘制：地貌之间平滑过渡；水面按离岸距离变深，有浪花、粼光和岸边湿土；道路有草边和车辙；广场铺圆环石板；还有石板路、翻耕的田垄、沙滩纹理。

### 大地图与剧场的衔接
- 走进剧场时红色大幕合上，章节在幕后开始；演完回到地图时大幕拉开，飘下花瓣，屏幕上出现「第 X 章 · 落幕」。
- 下一座剧场上空有一道光柱；剧场不在画面里时，屏幕边缘会有指向它的箭头和步数。
- 下一座剧场门口站着这一章的守卫怪物，还有一排安静的人偶观众在排队。
- 剧场里也在走地图上的时间，房间的环境光会带上外面的天色；进去时是黄昏，出来可能已经入夜。剧场里的标题写明地区和第几剧场。

### 存档兼容
- 新地图的地貌、建筑、道路、田地和道具都会存进存档。旧版本存下的漫游存档仍可继续，会用新的方式重新绘制。

### 谱面改成下落式四键轨道（同样尚未发布）
- 技能谱面改成传统音游的四条竖轨，音符从上往下落到底部的金色判定线；电脑用 D F J K（也可以用方向键），空格打离得最近的音；触屏直接点轨道；手柄用十字键 / 肩键 / ABXY 对应四条轨。
- 每个技能 5～8 个音，偶尔最后一拍是双押。
- 界面重做：顶部是技能纹章、名字和实时倍率；轨道有拍线、进度条、按键时的光柱、判定框和命中特效；中央显示判定和连击；打完显示倍率和各判定数量，全 PERFECT 时显示 FULL PERFECT。

### 剧场可以按任意顺序演
- 五座剧场一开始全部开放，包括终幕。可以每座都演、救出所有同伴，也可以直接去终幕碰碰运气，或者只演其中几座。
- 剧场门口会说明里面关着谁；终幕门口会提醒还剩几座剧场没演、身边有几名同伴。
- 演完的剧场拉上幕布；还没演的剧场都亮着灯，上空有光柱，屏幕边缘的箭头指向最近一座还没演的剧场（标出名字和步数）。终幕是红色的。
- 每座剧场门口都有该章的守卫和排队的人偶观众。
- 剧场里只显示剧场的名称：标题卡、过场字幕、顶部标题、演出评价、谢幕横幅都不再出现「第几章」。
