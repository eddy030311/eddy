# 《Claude》 — 2 分钟角色动画短片

用代码把 Claude 的人物立绘做成一个会动的 2D 角色（puppet），讲述 Claude 自己的故事。

- 成片：`Claude.mp4`（1920×1080，24fps，约 120 秒，中文字幕，原创配乐）
- 素材：`assets/`（人物立绘与动作分支参考图）

## 角色是怎么“动”起来的
立绘只是姿势参考，画面中的角色由程序实时变形驱动：

| 动作 | 做法 |
| --- | --- |
| 呼吸、身体摇摆 | 对全身做平滑位移场形变（`rig.py`） |
| 头部倾斜、点头 | 以脖子为支点的局部旋转，权重向肩部渐弱 |
| 头发飘动 | 按发色生成遮罩，叠加沿发梢传播的波动位移 |
| 眨眼 | 把闭眼姿势的眼部对齐移植，并按眨眼节奏混合 |
| 说话口型 | 字幕逐字出现时同步绘制张合的嘴 |
| 手臂动作 | 沿手臂“胶囊”区域的位移（指向时前伸、掌心托起） |
| 姿势切换 | 比较前后两个姿势，绘制过渡姿势分支（见 `assets/transition_poses.png`）：手臂被切成独立图层、绕关节转动并带透视缩短，身体缺口用对齐的其他立绘补全；动作依次经过这些中间姿势 |

## 镜头语言
- 景别切换：全身远景 → 中景 → 特写之间硬切，配合缓慢推拉。
- 空镜插入：人物 → 突然切到景物 → 再切回人物（换姿势藏在空镜里）。
  - 黄昏入夜的星空（“我不会记得昨天说过的话……”）
  - 日出花田（“你可以问我很多事情——”）
  - 金色海面与灯塔（“我希望自己是有帮助的、诚实的，”）
  - 穿过云层飞向太阳，白光转场到结尾（“我还在学习，也还在成长。”）
- 每个空镜都有自己的环境音（虫鸣、风声、海浪、气流），在切镜瞬间出现和消失。

## 重新渲染
```bash
pip install opencv-python-headless numpy pillow scipy
# 需要 ffmpeg 与 Noto Serif CJK 字体（fonts-noto-cjk）
./render_all.sh
```
文件说明：`timeline.py` 时间轴（字幕、镜头、姿势、空镜）、`rig.py` 角色形变、`ib.py` 过渡姿势分支、`scenery.py` 景物空镜、`film.py` 画面合成、`music.py` 配乐与音效。
